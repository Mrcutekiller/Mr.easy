How it works

From text to website
in four steps.

No prior coding experience. No complex setup. Just write and see.

01
💾
Install
Run the installer. It sets up the mreasy command and adds it to your PATH automatically.
installer\install.ps1
02
✏️
Write
Create a .mreasy file. Start with Mr.easy "Title" and write the rest in plain words.
Mr.easy "My Website"
03
⚡
Preview
Run mreasy run — browser opens instantly with live preview. Every change updates automatically.
mreasy run
04
🌐
Deploy
Run mreasy build to get a single HTML file. Upload to Netlify, GitHub Pages, or any host.
mreasy build
The language

No semicolons.
No brackets. Just words.

Indent to nest. Add words like big, glow, or blue to style any element instantly.

portfolio.mreasy
1Mr.easy "Biruk's Portfolio"
2
3# Navigation bar
4nav
5  logo "Biruk"
6  links Home Work Contact
7
8# Big hero section
9hero
10  title "Hello, I'm Biruk" big glow
11  subtitle "I build for the web"
12  button "View Work" blue big
13
14# 3-column project grid
15section "work"
16  grid cols:3
17    card shadow
18      icon rocket
19      title "Project" small
20
21footer
22  text "Made with Mr.easy 🇪🇹"
Mr.easy "Title"
Required first line. Like <!DOCTYPE html> in HTML — every .mreasy file must begin with this.
nav / hero / section
Layout containers. Indent inside with 2 spaces to add content.
title "Text" big glow
Heading. Add big medium small for size; glow for gradient effect.
button "Label" blue
Button. Color with blue red green purple orange. Add outline for ghost style.
grid cols:3
Responsive grid. Set columns with the cols: property.
card shadow glass
Content card. shadow adds depth; glass adds frosted effect.
repeat 3 times
Loop block. Use {index} inside to get the iteration number.
# comment
Lines starting with # are notes — completely ignored by the compiler.

Installation

Three ways to start.

Pick the method that works for you. Or skip it all and use the Web IDE.

01 — Recommended
Windows Installer
One command. Installs everything, registers the mreasy command, and creates a Desktop shortcut to the IDE.
1.
Open PowerShell as Administrator
Right-click → Run as Admin
2.
Run the installer
powershell -File installer\install.ps1
3.
Create your first project
mreasy new mysite
02 — Developer
npm install
For developers who prefer full manual control. Clone the project, install dependencies, and link globally.
1.
Install dependencies
npm install
2.
Register command globally
npm link
3.
Create and run your project
mreasy new mysite
03 — No Install
Web IDE
Zero setup required. Open in any browser, write code, see the result live, and download finished HTML.
1.
Open in your browser
ide/index.html
2.
Write and preview — no setup
Works instantly. Nothing to install. →
3.
Download your HTML
Click ⬇ Download in the IDE

The origin story

Built in Ethiopia.
For the whole world.

“Courage is clarity when the path is not yet written.”

MR.easy was created in Addis Ababa by Biruk — a developer who wanted the first step into web development to feel human. The spirit is familiar: make something useful with what you have, learn in public, and leave the door open for the next person.

The language is small on purpose. It is a beginning, not a wall. If you can describe a page, you can make one.

Biruk / creator of MR.easy / @mrcute_killer
Choose your starting point

Three ways to begin.

Use the command line, link it into your local workflow, or stay in the browser until the idea is ready.

01 / RECOMMENDED

Windows installer

One script adds the CLI to your path and gets a new project moving.

powershell -File installer\install.ps1
mreasy new mysite
02 / DEVELOPER

npm link

Clone the repo, install dependencies, and keep the compiler close to your work.

npm install
npm link

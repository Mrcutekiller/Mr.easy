Simple Workflow

From text to website
in four steps.

01
Install
Run installer script. Registers mreasy CLI command on your computer.
installer\install.ps1
02
Write
Create a .mreasy file. Start with Mr.easy "Title" and write words.
Mr.easy "My Website"
03
Preview
Run mreasy run — browser opens live preview that updates in real time.
mreasy run
04
Deploy
Run mreasy build to get a clean HTML file. Upload anywhere.
mreasy build

Rule 1: Signature
Every file MUST start with: Mr.easy "Title". This tells the compiler it's a valid Mr.easy document.
Rule 2: Plain Words
No brackets {} or semicolons ; needed. Write keywords directly like hero, title, button.
Rule 3: Indentation
Indent with 2 spaces to nest elements. Place cards inside grids, and titles inside hero blocks cleanly.
button "Label" blue
Button element. Style with color modifiers: blue red green purple orange.
grid cols:3
Responsive grid system. Set column count with cols: property.

The origin story

Built in Ethiopia.
For the whole world.

“Courage is clarity when the path is not yet written.”

MR.easy was created in Addis Ababa by Biruk — a developer who wanted the first step into web development to feel human. The spirit is drawn directly from the 1896 Battle of Adwa: a historic victory rooted in self-reliance, resourcefulness, and forging an independent path without relying on outside rule.

In modern web development, beginner tools are burdened by complex bundlers, heavy npm dependencies, and noisy syntax walls. MR.easy rejects that bloat to give anyone the power to create beautiful websites using plain human words.

Beginner Step-by-Step Guide

How to build websites with MR.easy

Whether you prefer using your PC's command line with VS Code or writing right inside your web browser, follow these simple steps.

💻 Method 1: Working on PC (CLI & VS Code)

Full local development experience with live auto-reloading.

1

Install MR.easy

Run installer\install.bat on Windows or execute:

powershell -ExecutionPolicy Bypass -File installer\install.ps1
2A

Option A: Automatic New Project

Creates a new folder mywebsite with starter files automatically:

mreasy new mywebsite
cd mywebsite
2B

Option B: Existing Folder / Manual File

If you already created your own folder or manual .mreasy file, just open terminal inside your folder:

cd path\to\your\folder
3

Start Live Server

Run live preview (automatically detects your code without overwriting anything):

mreasy run

Opens http://localhost:3000 in your browser with hot auto-reload!

4

Build Production HTML

When ready to publish or share your site, run:

mreasy build

Your compiled HTML is saved in dist/index.html.

🌐 Method 2: Web IDE (In Your Browser)

Zero setup needed. Write code and export your website instantly.

1

Open the Web IDE

Click the Open IDE button at the top or open ide/index.html in your browser.

2

Write MR.easy Code

Type keywords like hero, title, button, and card in the left editor panel.

3

Watch Real-time Preview

The right panel updates instantly as you type to show your visual website design.

4

Download Finished Website

Click Download ZIP in the topbar to download your complete HTML code package ready to deploy!

MR.easy Documentation

Master the simple, human-readable programming language that lets you build high-converting money-making websites in under 5 minutes.

1. Overview & How MR.easy Helps You

MR.easy eliminates technical code friction. Instead of wrestling with complex HTML tags, CSS bundlers, and npm errors, you write readable words to generate high-converting, responsive websites.

Why Creators Use MR.easy for Money Sites:

  • Instant Launch: Turn plain text into sales funnels in 5 minutes.
  • Zero Dependencies: Generates clean, standalone static HTML bundles ready to host anywhere.
  • Built-in Conversion UI: Premium dark mode, glassmorphic cards, call-to-action buttons, and responsive grid layouts out of the box.

2. Installation & Quick Start

Option A — PowerShell Quick Install (Windows)

POWERSHELL (ADMIN) 
powershell -ExecutionPolicy Bypass -File installer\install.ps1

Option B — Manual NPM Link

TERMINAL 
npm install
npm link

3. Language Core Syntax Rules

Every .mreasy file follows 4 golden rules:

  1. Declaration Line: The first line MUST start with Mr.easy "Page Title".
  2. Indentation defines hierarchy: Nested elements are indented using 2 spaces or tabs.
  3. Quotes for Multi-word Strings: Text containing spaces must be enclosed in double quotes "...".
  4. Comments: Lines starting with # are ignored during compilation.
INDEX.MREASY 
Mr.easy "My Money Site"

# Top Navigation Bar
nav bg:#080706 color:#f2ead8
  logo "MyBrand" size:22 color:#e8b45a

6. Style Modifiers & Custom CSS Rules

Modifiers can be applied inline directly after any tag:

  • bg:#hex or bg:url('...') — Set background color or image
  • color:#hex — Set text color
  • size:number — Set font size in px
  • radius:number — Set border radius in px
  • cols:1..6 — Set grid columns
  • padding:number — Set section padding in px
  • glow, glass, shadow, rounded, center — Visual presets

7. CLI Command Guide

CLI COMMANDS 
# Create a new project directory automatically:
mreasy new my-website

# Start live preview server with hot auto-reload:
mreasy run

# Compile standalone single file:
mreasy compile page.mreasy

# Build clean production HTML bundle:
mreasy build
